## 浏览 Dracovis Engine 项目

应用户要求浏览了整个项目，梳理了引擎架构。

### 项目概况
- **名称**：Dracovis Engine（缩写 DE），MIT 许可证，作者 wzy-2011，2025 年
- **类型**：自研 C++ 游戏引擎，ConsoleApp，C++20，Premake5 构建，x64
- **代码规模**：引擎核心 CodeFile 约 139 文件（58 cpp + 75 h + 5 hlsl），约 1.3 万行代码（不含 SWIG 自动生成的大文件）
- **解决方案**：`Dracovis Engine.sln`，含 5 个子工程（Dracovis Engine 主程序 + yaml-cpp / ImGui / Time / entt-master 静态库）

### 架构分层
1. **Application**（`CodeFile/Application/`）— 单例顶层协调者，管理双窗口（启动窗口+主窗口）、多线程资源加载、DX11/DX12 双模式切换（F5 热键）、ECS 场景调度、ImGui 编辑器面板
2. **ECS**（`CodeFile/ECS/`）— 基于 EnTT。Scene（生命周期 Unloaded→Loading→Active↔Paused→Unloaded）/ Entity / Components（Transform、SpriteRenderer、Rigidbody、Collider、Tag、Mesh）/ System（PhysicsSystem、MeshRendererSystem）
3. **Graphics**（`CodeFile/Graphics/`）— DX12 为新路径（DX12Renderer 封装 DX12Core/RenderTarget/DepthStencil/ImGui/Fence/RootSignature/DescriptorHeap/UploadBuffer/ShaderCompiler），DX11 已标记 `[[deprecated]]`
4. **Physics**（`CodeFile/Physics/`）— PhysX 5.5 封装，Physics 全局初始化 + PhysicsScene 步进 + PhysicsGeometry（Capsule）
5. **Input**（`CodeFile/Application/Window|Keyboard|Mouse`）— Win32 窗口与输入
6. **File I/O**（`CodeFile/FileController/Saver`）— yaml-cpp 场景/相机/光照/背景色序列化
7. **Shaders**（`CodeFile/Shader/`）— PBR + Solid（HLSL），Lighting.hlsli 共享头，支持最多 50 个点光源 + 聚光灯

### 第三方依赖
DirectX 11/12、DirectXTex/DirectXTK、EnTT、PhysX 5.5（14 个静态库）、Assimp（模型导入）、yaml-cpp、ImGui

### 资源
`Resources/` 含 Nanosuit、Cerberus、House、Cube、Geometry 等测试模型；`SceneData/` 存背景色/相机/光照/模型的 YAML 持久化数据

## 修复四个关键技术问题

### 1. DX11 光照显示问题
- **根因**：`Application::DoFrame()` 中 `LightManager::Update()` 在 `Bind()` 之前调用
- **修复**：调换顺序，Bind() 先收集光源，Update() 再打包到 CB（`Application.cpp:482-488`）

### 2. DX11 聚光灯形状错误
- **根因**：SolidConeDrawable 用实体三角列表渲染，与点光源球体难以区分
- **修复**：新建 `Bindable/Rasterizer.h/.cpp`，SolidConeDrawable 改用线框光栅化渲染

### 3. DX12 聚光灯索引错误
- **根因**：线框锥体 PSO 回退导致拓扑不匹配；异常未妥善处理
- **修复**：线框锥体无 PSO 时静默跳过；添加 _com_error / std::exception / catch(...) 分层异常处理

### 4. DX11 FBX 模型加载问题
- **根因**：缺少 aiProcess_GenNormals；assert(false) 在 Release 下不生效；noexcept 导致异常时 terminate
- **修复**：添加完整 Assimp 标志；空指针防护；改用 throw + try-catch 错误处理
